# T5.2 - FAQ whole-row click and expand

Status: approved (Stage 1 done at phase level, 2026-11-05). Implement directly. If the code contradicts this brief, stop and flag it.
Purpose: fix a functional bug (only the text and chevron toggle an FAQ, not the row) and make open and close smooth.
Depends on: T5.1.
Read first: `docs/design.md` (Motion).

## Files

`src/components/service-sections/FaqSection.tsx` (+ test), `src/components/layout/MobileMenu.tsx` (category accordion, + test), `src/app/motion.css`, new `tests/faq.spec.ts` (tag `@faq`, add to testing.md).

## Behaviour

- The padding moves from `<details>` onto `<summary>`, so the whole row, padding included, toggles with no JS. Add a hover background and an inset focus ring. The container uses `overflow-clip` so the rounded corners hold
- The chevron stays but becomes a round bordered chip (the "button" look). It is decorative (`aria-hidden`); the `<summary>` is the control. It rotates and its border turns accent when open
- Answer sits in its own padded block below the summary
- Block `details-expand` in `motion.css`, shared by FAQ and the `MobileMenu` accordion:
  - Everywhere: the answer fades and rises 8px on open (`faq-in`, time-based, inside the no-preference guard)
  - Chromium only (`@supports selector(::details-content)` and `(interpolate-size: allow-keywords)`): `::details-content` animates `block-size` and `content-visibility` with `transition-behavior: allow-discrete`
  - Safari and Firefox get the fade only. Close is instant there. Accepted
- Keep every item closed on load. No exclusive-accordion `name`

## Accessibility

Native `details`/`summary`: keyboard, screen reader and no-JS behaviour unchanged. One interactive element per row. Visible `focus-visible` ring.

## Tests

- Playwright: on a service page with FAQs, clicking the far corner of a `summary` (inside the padding) opens it, a second click closes it. Run at 375 and 1280. Locate with `summary` (it has no role)
- Vitest: keep the existing three. Add: the question text sits inside the `summary`
- `@motion` guards still pass (answer is never left faded)

## Manual check

Tap the empty edge of an FAQ row on a phone. Open and close in Chrome, Safari and Firefox. Open the mobile menu categories.

## Out of scope

Exclusive accordion, FAQ copy, other `details` uses.
