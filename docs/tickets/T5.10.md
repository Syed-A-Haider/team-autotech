# T5.10 - Service pages

Status: approved (Stage 1 done at phase level, 2026-11-05). Implement directly. If the code contradicts this brief, stop and flag it.
Purpose: medium-intensity motion on all 15 service pages, through the shared blocks only.
Depends on: T5.3, T5.5.
Read first: `docs/design.md` (Motion).

## Files

`ServiceHero.tsx`, `ServiceSections.tsx` and blocks (`StepsSection`, `FeatureSection`, `SpecBand`, `ProseSection`, `VideoSection`), `ServicePageTemplate.tsx`, new `ui/ScrollProgress.tsx` (Server), `motion.css`, tests of the same names.

## Behaviour

- `ServiceHero`: text uses `hero-in-1/2/3` (reuse T5.5). The category motif gets a slow `scale` settle. No scroll effect
- Numbered sections already animate through `SectionHeading` (T5.3). Glow stays static
- Steps: `reveal-stagger` on the list; the number badge scales in (keep the skew and the un-skewed inner number)
- Feature: `alternating` uses `reveal-left`/`reveal-right`; `grid` and `list` use `reveal-stagger`. Cards keep their own hover
- SpecBand: cells in `reveal-stagger`. Prose: one `reveal` on the block, not per paragraph. Video: `reveal` on the facade only
- Scroll progress bar (approved, service pages only): a 2px accent bar fixed under the Navbar (`top-16`, inside the z-index scale), `scaleX` bound to `scroll(root)`, origin left, inside the scroll guard. Rendered by `ServicePageTemplate`. Easy to drop in one line if Syd finds it too much
- Count-up numbers are rejected

## Rules

`FeatureSection` cards use `overflow-hidden` today: reveal the wrapper, never an element inside an `overflow-hidden` ancestor (use `overflow-clip`). The CTA band and Related Services belong to T5.11.

## Tests

`@motion` guards on two more service pages (a split-layout page and one with a video). Vitest: `ScrollProgress` renders an `aria-hidden` element; existing block tests unchanged.

## Manual check

A long service page on a phone: smooth scroll, progress bar tracks, nothing jumps near the Navbar, anchor jumps clear it. Compare a live page with a coming-soon page.

## Out of scope

Closing bands, Related Services.
