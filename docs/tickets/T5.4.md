# T5.4 - Press, sheen, lift and nav polish

Status: approved (Stage 1 done at phase level, 2026-11-05). Implement directly. If the code contradicts this brief, stop and flag it.
Purpose: instant tactile feedback on phones and polished hover on desktop, site-wide.
Depends on: T5.1.
Read first: `docs/design.md` (Motion).

## Files

`src/app/motion.css`, `LinkButton.tsx`, `ServiceCard.tsx`, `WhatsAppWidget.tsx`, `Navbar.tsx`, `ServicesDropdown.tsx`, `MobileMenu.tsx` (toggle button only), `Footer.tsx` (social icons), tests of the same names.

## Blocks

- `press`: `touch-action: manipulation`, tap highlight off, `motion-safe:active:scale-[0.97]` over `--motion-fast`. On every `LinkButton`, `ServiceCard`, the menu toggle, social icons and the WhatsApp widget
- `sheen`: a pseudo-element gradient sweep across the button, one pass. On `LinkButton` primary only. Hover only (hover media), so no sticky effect on touch. Needs `relative overflow-clip` on the button
- `lift`: `motion-safe:hover:-translate-y-1` plus the accent border. No shadow animation (not compositor friendly). On `ServiceCard`, with a small icon nudge
- Navbar links and dropdown rows: underline draws from the left (`scale` X on a pseudo-element) on hover and `focus-visible`
- `WhatsAppWidget`: one attention pulse ring on load, two cycles, then still (`animation-iteration-count: 2`, delayed about 3s). Off for reduced motion. `motion-safe:hover:scale-110` stays

## Rules

Hover effects only under the hover media query (Tailwind `hover:` already is). Press is the touch feedback. No backdrop-filter on the header. Keep existing focus rings.

## Tests

- `LinkButton.test.tsx` asserts classes; edit only what the change forces (the rewrite stays a separate follow-up)
- `@motion` guards (the pulse ring must not leave anything faded or shift layout)
- Vitest: no new behaviour to assert beyond existing roles and hrefs

## Manual check

Tap buttons and cards on a phone (press shrinks, no stuck hover). Hover on desktop. Tab through the Navbar. The widget pulses twice then stays still.

## Out of scope

Hero, grid reveals, carousel arrows (T5.7).
