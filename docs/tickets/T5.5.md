## Files

`src/app/motion.css`, `HeroSection.tsx`, `ServicesGrid.tsx`, `src/app/globals.css` (`page-enter`), `PageTransition.tsx`, their tests.

## Behaviour

- Hero image settles from `scale 1.06` to 1 over about 1.2s (transform only, never opacity)
- Block `hero-in-1/2/3` (timed, no-preference guard): headline, subtitle and call button rise in, staggered 0, 120 and 240ms. LCP rule: the baseline says the LCP element is the hero image, so text may fade, but check LCP again; if it regresses over 100ms, make the headline translate-only
- Call button gets one `sheen` pass on load (phone is where it shows)
- `ServicesGrid`: the six cards use `reveal-stagger`, each card on a wrapper `div` (reveal on the wrapper, lift and press on the card). Heading uses `reveal`
- `PageTransition`: the baseline shows it costs about 180ms of LCP (over the 100ms line). Change `page-enter` to start at `opacity: 0.6` and run 150ms, and make sure it does not stack with `hero-in` into a double fade. Re-measure
- No parallax, no scroll effect on the hero
