# T6.4 - Shop (inactive) in the top nav

Status: planned. Meaning confirmed by Haider on 2026-11-07 (the default below). Stage 1 still needed.
Purpose: Syd asked for "a new column at the top - Shop (inactive)". The shop itself is deferred to Phase 8. This only shows that it is coming.
Depends on: T6.1 (same files).
Read first: `docs/design.md` (nav, Motion), `docs/conventions.md`.

## Default reading

A non-clickable "Shop" label with a small "Coming soon" tag in the top nav after About, on desktop and in the mobile menu. Not a `/shop` page, not a dropdown column. If Syd means something else, change the brief before building.

## Files

`Navbar.tsx`, `MobileMenu.tsx`, `lib/constants.ts` for a shared label (a non-component export from a `'use client'` file cannot be imported by a Server Component), tests.

## Behaviour

- Plain text, not a link, not a button, not focusable, default cursor
- Accessible text "Shop (coming soon)"
- No `press`, no `underline-draw`
- Muted colour token, never `opacity-*` (the `@motion` "nothing left faded" guard reads computed opacity)

## Tests

Vitest: Navbar and MobileMenu render "Shop" with the status text, and no link or button is named Shop. Run the existing `@motion` faded guard and `@interaction`.

## Docs

`design.md` (nav), `architecture.md` (Phase 8 note).

## Out of scope

A shop page, basket, any Phase 8 work.
