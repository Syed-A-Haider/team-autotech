## Brief vs code (corrections)

- `redirects.test.ts` requires a root-slug redirect for every service. The nine slugs need `SERVICE_SOURCES` entries with no aliases (the old brief missed this). The `@redirects` spec grows by itself.
- `services-data.spec` loops over `getAllServices()`, so it grows from 15 to 24 with no edit.
- `Unlock` is an old alias of `LockOpen` in lucide-react 1.30.0. Use `LockOpen`.
- `FeatureSection`'s five-item plan puts the wide card first on `sm`. About wants the last one wide, so it has its own literal span list.
- Column widths with no scrollbar: about 173px at 1024 (`gap-5 p-6`) and about 186px at 1280 (`gap-8 p-8`).
- "MECHANICAL / CUSTOMISATION" always wraps to two lines, so the dropdown uses subgrid to start every list level.
- `heroPages` alone does not test the new motif, because the "motif settles" test ran on one slug only.
